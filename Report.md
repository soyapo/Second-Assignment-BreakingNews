# Project Title

News Aggregator, a simple console based tool to review recent news of a certain topic.

## Description

News Aggregator helps you review various recent news, with the possibility to customize the search query and  timespan.

## Getting Started

   This tool uses NewsAPI.com 's API to retrieve news and display them through parsing JSON strings.
   
### Dependencies

* Google GSON for handling JSON in Java.

### Executing program

run Infrastructure.Class
